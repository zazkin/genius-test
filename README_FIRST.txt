ЭТО DESKTOP-ВЕРСИЯ БЕЗ АДАПТИВА.

1. Сначала просто открой index.html через Live Server.
   css/main.css уже готов — ничего компилировать не нужно, чтобы проверить результат.

2. Когда будешь менять SCSS, запускай Sass ИЗ КОРНЯ ПРОЕКТА вот так:

   sass --watch scss/main.scss css/main.css

   Не нужно компилировать каждую папку отдельно и потом переносить сгенерированные папки вручную.

3. Структура специально оставлена простой:
   scss/abstracts  — переменные
   scss/base       — базовые правила
   scss/components — кнопки, карточки, формы, заголовки
   scss/layout     — container, header, footer, modal
   scss/pages      — секции страницы
   scss/main.scss  — подключает всё вместе

4. Адаптива и @media здесь нет. Добавишь позже, когда дойдёшь до этой темы.

5. Шрифт Poppins подключён через Google Fonts, потому что старые локальные файлы в проекте были только Latin и не содержали украинские/кириллические буквы.
